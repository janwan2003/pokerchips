A poker chip app that runs in the browser

Most poker chip apps make every player download something. EasyPoker runs in the browser: the host opens a table, everyone else scans a QR code, and the chips live on each player's own phone.

What a good poker chip app needs to do

A poker chip app (sometimes called a poker chip tracker) replaces the chip set in a live game. After many home games, this is the list that matters:

  • One stack per phone. Each player controls their own chips. A single shared tablet that everyone has to reach for is slower than real chips.
  • A pot everyone can see. Bets show up on every screen at once, so nobody asks "what's the pot?"
  • Blinds built in. The current small and big blind are always visible, and the host can raise them between levels.
  • Mistakes are fixable. Someone will tap the wrong amount. The host needs to correct a stack or undo the last few moves without restarting.
  • Nothing gets lost. A dead battery, a closed tab or a dropped Wi-Fi connection must not wipe anyone's chips.
  • Zero setup for guests. If joining takes more than a minute, people go back to counting coins.

Poker chip app, tracker or counter: what's the difference?

People search for all three, and they usually mean slightly different things:

  • Poker chip app: replaces chips completely. Every player bets on a phone. This is what EasyPoker is.
  • Poker chip tracker: one person records stacks or buy-ins while the group still uses physical chips. Useful for cash games, but someone has to keep typing.
  • Poker chip counter: works out what a pile of chips is worth, or how to split a chip set between players. Our poker chip calculator does both, if you are sticking with physical chips.

Why a browser app instead of an app store download?

At a home game, the slowest part of any app is getting everyone to install it. Somebody is on iPhone, somebody is on Android, somebody's storage is full, somebody does not want another account. A browser table avoids all of that: one link, and every phone is in.

The host also does not need to stay on one device. The host link can be copied to a laptop or another phone, which helps if the host's own battery is running low.

Frequently asked questions

Is there a poker chip app for both iPhone and Android?

EasyPoker runs in any modern phone browser, so iPhone and Android players can sit at the same table. Nothing needs to be installed.

Does the poker chip app work without internet?

The browser version needs a connection, because the stacks sync through the server. Mobile data is enough; each action is a tiny message.

Can I track buy-ins and re-buys?

Yes. The host can allow buy-ins of a fixed amount when creating the table, and can also set any player's stack directly.

Does it deal cards?

No. It is a chip app: deal a normal deck at the table.

Is it really free?

Yes, with no account and no ads in the game.
