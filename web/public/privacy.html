Privacy

Last updated 2026-11-12

EasyPoker has no accounts, no ads and no cookies. It does keep cookie-free usage statistics, described below. This page lists everything the site keeps.

What is stored about a table

  • The table itself: its code, starting chips, blinds and buy-in settings.
  • Player names exactly as typed when joining. Use a nickname if you prefer.
  • Every action at the table (bets, pots taken, host corrections), each with a timestamp, so stacks survive a closed tab and the host can restore an earlier moment. This history is kept and is not deleted.

What is stored in your browser

Your browser's own storage remembers the name you last used and, for the host, a secret host key for each table you created. It never leaves your device except when you use the host features of that table. No cookies are set.

Usage statistics

To see how the site is used, EasyPoker records each page view and each table event (a table created, a player joining, a bet or other action). Each record holds the page or action, the table code and player name where there is one, the approximate location Cloudflare derives from your connection (country, region, city), the referring site, whether the device is a phone or a computer, and the network operator. Visitors are counted with a hash of the IP address and browser that changes every day, so no IP address is stored and a visitor cannot be followed from one day to the next. These records are kept for three months.

Pages also load Cloudflare Web Analytics, a cookie-free script that reports page views and load times to Cloudflare without identifying you.

Third parties

  • Cloudflare hosts the site and the tables and, like any web host, sees standard request information such as IP addresses. It also stores the usage statistics above.
  • Google Fonts serves the typefaces, so your browser requests them from Google.

Money

EasyPoker only tracks chip counts. It does not handle payments or real money of any kind.
