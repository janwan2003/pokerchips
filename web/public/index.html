Virtual poker chips for a live home game

EasyPoker is a free poker chip tracker that runs in the browser. Play with a real deck; the chips live on everyone's phone.

Is EasyPoker free?

Yes. Hosting and joining a table is free, with no account, no app download and no ads.

Do players need to install an app?

No. Each player opens the table link or scans the QR code in their phone's browser and types a name. That is the whole setup.

How many players can join one table?

Up to 30. The host sets the starting chips and the blinds, and can allow buy-ins of a fixed amount.

Does EasyPoker deal the cards?

No. You deal a real deck at the table. EasyPoker replaces only the chips: every stack, bet and pot is kept on the players' phones and updates on all of them at once.

What happens if a phone dies or a tab closes?

Nothing is lost. Every action is saved on the server as it happens, so a player reopens the link and carries on. The host can also correct any stack or the pot, or rewind the table to an earlier moment.

Is it real-money gambling?

No. EasyPoker tracks play chips for a game among friends. It never handles money, sells chips or pays out.
